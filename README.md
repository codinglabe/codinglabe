## 👨‍💻 About Me

I'm **Nazrul Islam**, a **Laravel & React full-stack developer** from Jessore, Bangladesh 🇧🇩 with **5+ years** of experience. I build, improve and troubleshoot production web apps — from **Laravel / PHP** back-ends and REST APIs to **React** and **Next.js** front-ends built from Figma designs.

- 🏔️ Built a **tourism booking platform** (Laravel 11 API + Next.js site + React admin panel)
- 🎥 Working on **video-meeting apps** with Next.js and custom **WebRTC** signaling
- 💬 Built a **real-time chat** with Node.js, Express, Socket.IO and MongoDB
- 💳 Integrated **payments** in Laravel apps (Laravel Cashier, PayPal IPN, FedaPay)
- 🚀 Ship with **GitHub Actions** deploys to **AWS EC2** and **Vercel**
- 🔌 REST APIs & third-party integrations, including **Stripe** and **PayPal**
